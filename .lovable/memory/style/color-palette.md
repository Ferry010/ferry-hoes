**Editorial 2026 palette — teal is killed entirely.**

- Background (page): warm cream `#F6F1EA` → `--background`
- Background (alt sections): deeper cream `#EFE7DB` → `--background-alt`
- Ink (body + headlines): near-black `#0F1115` → `--foreground`
- **Primary accent (the only brand color)**: orange `#F2542D` → `--primary` AND `--accent`
- Quiet ink-navy (handwritten captions, BHI card): `#0B2447` → `--ink-navy`
- Muted text: `#5C5A55` → `--muted-foreground`
- Hairline / border: `#E3D9C9` → `--border`

Rules:
- Orange `#F2542D` only on cream or as button fill. Never as body text. Never on white.
- The "Ferry signature" headline period is always orange.
- BHI card uses ink-navy bg + orange accent. AIGA card uses purple `#3B1F6B` + amber accent.
